# FAQ
**Kenapa kamera kadang offline?** Sumber pemerintah maintenance / gangguan; checker memberi grace 3 hari sebelum menghapus.
**Kenapa tidak ada web/player?** Fokus repo = playlist + data; pemutaran lewat VLC/app IPTV.
**Kenapa beberapa sumber tidak dipakai?** Bertoken/sementara (Kab Banjar), MJPEG (Banyuasin), atau diblokir Cloudflare (Tabalong/OKU) — tidak stabil/aksesibel dari runner.
**Cara pakai?** Salin URL playlist (atau mirror jsDelivr) ke VLC / TiviMate / OTT Navigator.
**Cara tambah kamera?** Buka issue "Usul kamera baru"; maintainer verifikasi stabilitas.
**Apa itu mudik-mode?** Frekuensi cek naik saat libur; aktifkan variable repo `MUDIK=on`.
**Data boleh dipakai?** Ya, open data (MIT); sitasi via release/Zenodo bila ada.
